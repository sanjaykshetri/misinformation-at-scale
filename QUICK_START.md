# Quick Start Guide

## 🚀 Pick Your Path

### 🟢 Option A: Start TODAY (Synthetic Data) — 30 minutes

**Best for:** Immediate demonstration, getting started fast, testing code

No data download needed. Full pipeline works immediately with generated data.

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run notebooks
jupyter notebook notebooks/01_data_wrangling.ipynb
```

**What happens:**
- Notebook auto-generates 10k synthetic comments
- All 4 notebooks run end-to-end
- Models train and evaluate
- Takes ~2-3 hours to complete all 4 notebooks
- Perfect for Springboard/recruiter demo

**Next:** After demo, follow Option B to add real data

---

### 🟠 Option B: Add Real Data (BigQuery) — 1-2 hours

**Best for:** Real results, recruiters, Springboard final project

Get actual Reddit data without downloading 50GB.

```bash
# 1. See BIGQUERY_SETUP.md (15 min setup)
#    - Create free Google Cloud account
#    - Enable BigQuery API
#    - Run sample query

# 2. Query Reddit data (2 min)
#    - Copy-paste query from BIGQUERY_SETUP.md
#    - Gets 100k-1M real comments

# 3. Download CSV
#    - BigQuery exports to `reddit_comments_2020.csv`
#    - Save to `data/raw/`

# 4. Run notebooks (they auto-detect real data)
jupyter notebook notebooks/01_data_wrangling.ipynb
```

**What happens:**
- Notebooks automatically load real Reddit CSV
- Same pipeline but with actual data
- Models trained on real misinformation/control subreddits
- Production-ready results

---

### 🔴 Option C: Download Full Archive — 12+ hours

**Best for:** Maximum authenticity, full analysis

Download raw files from Academic Torrents (requires 50GB+ storage).

```bash
# 1. Download from https://academictorrents.com/
#    Search: "RC_2020" → Download .torrent
#    Each file ~5-6GB, download 1-2 months

# 2. Decompress
python prepare_data.py --all

# 3. Run ingestion
python src/ingest.py

# 4. Run notebooks
jupyter notebook notebooks/01_data_wrangling.ipynb
```

## 🔧 Configuration

All parameters in `config/settings.yaml`:

```yaml
ingestion:
  misinformation_subreddits:
    - conspiracy
    - theDonald
    - NoNewNormal
  
  control_subreddits:
    - science
    - askscience
    - news
  
  time_window:
    start_date: "2020-01-01"
    end_date: "2020-12-31"
```


## 🆘 Troubleshooting

### "I don't want to download huge files"
→ Use **Option A** (synthetic) or **Option B** (BigQuery)

### "I want real Reddit data but not 50GB"
→ Use **Option B** (BigQuery) — query exactly what you need

### "I want the most authentic analysis"
→ Use **Option C** (full archive) — takes time but most complete

### "Notebooks won't run"
→ Make sure `pip install -r requirements.txt` completed

### "No data found" error in notebook
→ Notebooks auto-generate synthetic data — this is normal!
